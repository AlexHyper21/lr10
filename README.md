# ЛР 10 — веб-доступность (a11y) по WCAG 2.1

Клиент «пиксельмаркет» (вариант 3) после аудита и исправления нарушений доступности. Исходная версия до исправлений — проект `lr9`.

## Что исправлено

| Компонент | Исправление |
|---|---|
| Модальное окно быстрого просмотра (`QuickViewModal`, `Dialog`) | `role="dialog"`, `aria-modal`, `aria-labelledby/-describedby`, ловушка фокуса (Tab / Shift+Tab), закрытие по `Esc` и клику по фону, возврат фокуса на кнопку-триггер, фон блокируется атрибутом `inert` |
| Подтверждение очистки корзины | `role="alertdialog"`, начальный фокус на «Отмена» |
| Карточки товаров | контраст цен, бейджей и кнопок ≥ 4.5:1, порядок заголовков h1 → h2, `del` для старой цены, скрытые подписи «Цена», «Скидка», «Рейтинг» для скринридеров |
| Навигация | `aria-label` у иконочных ссылок, `aria-label` корзины с количеством, ссылка «Перейти к основному содержимому», видимый фокус |
| Селектор количества | подписи «Уменьшить / Увеличить количество», «Количество» |

## Запуск

```bash
npm install
npm run dev
```

http://localhost:5173 (данные — из API ЛР 8 на порту 5000).

## Аудит

- Chrome DevTools → Lighthouse → Accessibility → Analyze page load;
- расширение axe DevTools → Scan all of my page.
